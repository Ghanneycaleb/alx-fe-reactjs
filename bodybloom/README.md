# 💪 BodyBloom - Fitness Tracker

A modern fitness tracking application built with React, Tailwind CSS, and the WGER API.

## 🌟 Features

- **Workout Logging**: Track exercises, sets, reps, and weights
- **Exercise Database**: Browse exercises from WGER API
- **Progress Tracking**: Visualize your fitness journey with charts
- **Workout History**: View and manage past workouts
- **Motivational Quotes**: Stay inspired with daily motivation
- **Music Suggestions**: Get workout playlist recommendations

## 🛠️ Tech Stack

- **React 18** - UI Framework
- **Vite** - Build Tool
- **Tailwind CSS** - Styling
- **Axios** - API Requests
- **Recharts** - Data Visualization
- **WGER API** - Exercise Database

## 📦 Installation
```bash
# Clone the repository
git clone https://github.com/YOUR-USERNAME/bodybloom.git

# Navigate to project directory
cd bodybloom

# Install dependencies
npm install

# Start development server
npm run dev
